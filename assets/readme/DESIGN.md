# H안 · 기술 발표형 README 시각 계약

## 참고와 적용 범위

시각 참고: [Google 블로그의 Gemini 기술 발표](https://blog.google/intl/ko-kr/products/gemini-4-argon-kr/).
큰 제목·설명문·날짜로 시작하는 기사형 도입, 넓은 여백, 파란색 강조 열이 있는 비교표,
0부터 시작하는 파랑·회색 비교 차트의 구성을 프로젝트 자료에 맞게 적용했습니다.
브랜드 로고·제품 이미지·기사 문장을 복제하지 않습니다. 아래 색은 이 프로젝트의
접근성·가독성을 위해 선택한 색이며 공식 브랜드 토큰이나 Google의 보증을 뜻하지 않습니다.
참고 페이지는 디자인 출처일 뿐, 항공편 데이터나 성능 수치의 근거가 아닙니다.

H안은 `design/technical-launch-h`의 별도 시안입니다. 기존 F 메인 디자인을 대체하거나
병합했다는 뜻이 아닙니다. README의 CI 배지는 H 브랜치를 가리킵니다.

## 표현 규칙

- 전체 SVG의 `data-design`은 `technical-launch-h`
- 본문 잉크 `#202124`, 강조 파랑 `#185ABC`, 비교 대조군·구분선 회색 `#DADCE0`
- 흰색 바탕과 옅은 파란색 강조 영역, 장식용 그라데이션 없이 수치를 읽는 계층을 유지
- 회색은 도형의 대조군 표현에 사용하며 텍스트는 읽을 수 있는 짙은 색으로 표시
- 1600 단위 너비, 표지 높이 1000, 모든 SVG 텍스트 크기 28 이상
- 시스템 한글 산세리프 폰트만 사용하며 외부 폰트·이미지·스크립트에 의존하지 않음
- 5개 정량 그림은 서로 다른 차트 문법을 사용하고, 3개 설명 그림과 함께 총 8개 SVG를 유지
- 전처리 비교표는 네 조건의 평균·표준편차를 모두 제시하고 `P6_clean` 열을 파란색으로 강조
- 강조 열은 현재 기준 조건을 안내하는 표시이며, 최고 성능이나 유의한 우월성을 뜻하지 않음
- 날씨 비교의 막대는 0에서 시작하며 날씨 미사용은 회색, 날씨 사용은 파란색으로 표현
- 지표별 막대는 원본 평균을 표현하고, 같은 지표의 두 조건은 같은 기준선·축 범위를 공유
- 막대의 높이/너비는 원본 값에 비례해야 하며 변화량을 크게 보이게 하는 절단 축을 쓰지 않음
- 서로 다른 지표의 척도와 방향을 구별하며 변화량 크기를 지표 간 직접 비교하지 않음

## 변경하지 않는 근거

`../../scripts/build_readme_assets.py`는 추적된 5개 집계 파일만 읽습니다.
`sources.json`에는 원본 경로·SHA256, 선택 필터, 원래 정밀도의 수치, 생성기와 SVG 해시를 기록합니다.
디자인을 바꿔도 원본·필터·수치는 그대로 유지합니다. 별도 테스트에 고정한 집계 계약은
생성기와 영수증을 동시에 수정하더라도 의미 변화를 검출합니다.

- 전체 원본 1,000,000행; 라벨 255,001행; 날짜 귀속 채택 706,759행
- 날짜 귀속의 세 집단 706,759 / 291,308 / 1,933행은 서로 겹치지 않으며 합계 1,000,000행
- 날씨 비교는 같은 라벨 180,332행, 시드 42 / 1 / 7, 같은 외부 폴드와 내부 선택 절차
- `P6_clean` 기존 입력에 날씨 14개 피처를 추가한 비교이며 전처리 평가 집단과 구별
- Macro F1 0.573910 → 0.598945, 변화 +0.025035
- LogLoss 0.448116 → 0.436689, 변화 −0.011428
- ROC-AUC 0.640618 → 0.672936, 변화 +0.032317
- 변화량은 날씨 사용−미사용이며 표시된 평균을 다시 빼지 않고 원본에서 각각 반올림
- 3시드 표준편차는 신뢰구간이 아니며 통계적 유의성이나 동등성을 의미하지 않음
- 10분 공개 지연은 실측값이 아닌 가정이며, 정적 교차검증을 인과 효과·미래 운항 성능으로 일반화하지 않음
- 결합률 그림은 수집 가능한 268행을 분모로 하는 8개 이산 시나리오이며 모델 성능 그림이 아님
- README의 기존 19개 코드 블록, 8개 그림, 개별 근거 링크와 해석 한계를 보존

## 재현과 검증

저장소 루트에서 실행합니다. 원시 데이터, 네트워크 접속, 수집·학습 실행은 필요하지 않습니다.

```sh
python scripts/build_readme_story.py
python scripts/build_readme_assets.py
python scripts/build_readme_assets.py --check
python -m pytest tests/test_readme_presentation.py tests/test_readme_contract.py
```

테스트는 해시·원본 의미·단위·분모·접근성·0 기준 막대의 실제 좌표·독립적인 재생성 일치를 확인합니다.
